# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。记录可挂多个标签（如工作、生活），时间轴支持按标签筛选，年报展示每个标签下的情绪分布。数据保存在浏览器 `localStorage`。

## 标签规则

- 一条记录可挂多个标签；种植、时间轴、年报共用同一份标签数据，改名或删除后三处立即同步
- 标签可以改名；改成已存在的名字时自动合并两个标签，各自名下的记录都归到合并后的标签（去重，记录一条不丢）
- 删除标签只解除与记录的绑定，历史记录保留并回到「未分类」，不会连同记录一起删除
- 旧版本地数据加载时自动迁移：缺失的 `tags` / `tagIds` 会补齐，历史重复标签自动归一

## 分层

- 核心层 `src/core`：情绪记录、连续天数、植物生长阶段、枯萎判断、生态年报、标签的增改删 / 合并 / 解绑（`tag-engine.ts`）
- 端口层 `src/ports`：花园快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图
