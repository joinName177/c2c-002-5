# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。数据保存在浏览器 `localStorage`。

## 标签

- 一条记录可挂多个标签（如工作、生活），也可不挂（未分类）
- 标签数据全应用共用一份：种植、时间轴筛选、年报标签分布引用同一份标签
- 标签可改名，所有引用处立即同步；改成已存在的名字会合并两条标签，双方名下记录都归到保留的标签
- 删除标签只解除绑定，历史记录保留并回到未分类，不会删除任何记录

## 分层

- 核心层 `src/core`：情绪记录、标签增改/合并/解绑、连续天数、植物生长阶段、枯萎判断、生态年报
- 端口层 `src/ports`：花园快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图

